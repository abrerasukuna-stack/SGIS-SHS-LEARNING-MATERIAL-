NETWORK SERVICES

DNS & DHCP Configuration

Dalawang importanteng serbisyo na tumutulong para madaling mahanap ang devices at ma-configure ang IP addresses sa network.

1. DNS — Domain Name System

Isinasalin ng DNS ang hostnames at domain names sa IP addresses o ibang records. Sa domain network, mahalaga ang tamang DNS configuration para mahanap ang domain services.

  • A record: hostname papunta sa IPv4 address.
  • AAAA record: hostname papunta sa IPv6 address.
  • CNAME: alias ng ibang pangalan.
  • PTR: reverse lookup mula IP papunta sa pangalan.

2. DHCP — Dynamic Host Configuration Protocol

Nagbibigay ito ng IP configuration sa clients, gaya ng IP address, subnet mask, default gateway, at DNS server.

01DiscoverClient naghahanap ng DHCP server.
02OfferServer nag-aalok ng configuration.
03RequestClient humihiling sa napiling offer.
04AcknowledgeServer kinukumpirma ang lease.

3. Safe setup workflow

  1. Alamin ang subnet, gateway, DNS server, at kasalukuyang DHCP scope.
  2. Planuhin ang address range at exclusions para sa devices na may static IP.
  3. Sa authorized server, i-install at i-configure ang DNS/DHCP roles ayon sa Windows Server version at lab guide.
  4. Sa DHCP scope, itakda ang valid range, lease options, gateway, at DNS server values na ibinigay ng administrator.
  5. Kung domain environment ang gamit, i-authorize ang DHCP server sa Active Directory kung kinakailangan.
  6. Sa client test PC, renew ang lease at tiyaking tama ang IP at DNS configuration.
Critical: Huwag magpatakbo ng rogue DHCP server sa school/home/office network. Maaari nitong sirain ang network access ng ibang devices. Gumamit ng isolated lab o pahintulot ng network administrator.

4. Useful Windows commands

View current IP settings
ipconfig /all
Release and renew DHCP lease
ipconfig /release
ipconfig /renew
Test DNS name lookup
nslookup lab-server

Palitan ang sample hostname ng valid hostname sa inyong lab. Ang eksaktong role wizard at commands ay maaaring mag-iba depende sa OS/version at permissions.
