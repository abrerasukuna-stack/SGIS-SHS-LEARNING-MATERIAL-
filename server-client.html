Server & Client Deployment

Matutunan ang basic network planning at kung paano nakakonekta ang client computer sa server.

Learning goal

Sa dulo ng lesson, maipapaliwanag mo ang role ng server at client at makakapagsagawa ng basic connection checks.

1. Mga pangunahing konsepto

Server — computer na nagbibigay ng network services o resources. Client — device na gumagamit ng mga resources na iyon.

  • IP address: address ng device sa network.
  • Subnet mask: tumutukoy sa network at host portion ng address.
  • Default gateway: daan papunta sa ibang network, kung kailangan.
  • DNS: tumutulong hanapin ang host gamit ang pangalan nito.
  • DHCP: awtomatikong nagbibigay ng network configuration.

2. Ihanda ang network

  1. Alamin kung aling computer ang server at alin ang client.
  2. Ikonekta ang devices sa parehong switch/router o isolated lab network.
  3. Gumawa ng IP plan. Sample lamang: server 192.168.10.10, client 192.168.10.21, subnet mask 255.255.255.0.
  4. Siguraduhing walang duplicate IP at hindi sumasapaw ang static IP sa DHCP pool.
Important: Sample IP addresses lang ang mga ito. I-check muna ang kasalukuyang network settings bago mag-configure.

3. General deployment steps

  1. I-install at i-update ang operating system.
  2. Gumamit ng madaling makilalang computer names, gaya ng LAB-SERVER at LAB-PC01.
  3. I-configure ang network adapter ayon sa IP plan.
  4. I-enable lamang ang services na kailangan ng lab.
  5. Gumamit ng malakas na password at least-privilege permissions.
  6. I-configure ang firewall para sa kinakailangang service; huwag itong i-disable nang buo.

4. Verify connection

Sa Windows client, buksan ang Command Prompt:

ipconfig
ping 192.168.10.10

Palitan ang sample IP ng aktuwal na server IP. Ang successful ping ay nagpapakita ng reachability, ngunit hindi nito ginagarantiya na gumagana ang lahat ng server services.
