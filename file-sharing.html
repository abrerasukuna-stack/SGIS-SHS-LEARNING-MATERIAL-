File Sharing & Permissions

Magbahagi ng files sa network habang pinoprotektahan ang data gamit ang tamang access permissions.

1. Bakit gumagamit ng file sharing?

  • Madaling magbahagi ng learning materials at documents.
  • Hindi kailangang maglipat ng files sa USB sa bawat computer.
  • Maaaring i-manage ang access batay sa users o groups.

2. General setup sa Windows

  1. Gumawa ng folder para sa files na puwedeng i-share, halimbawa C:\\LabShare.
  2. Huwag ilagay ang personal/confidential files sa shared folder.
  3. Buksan ang folder Properties at hanapin ang Sharing options.
  4. I-enable ang sharing para sa authorized user/group at magtakda ng share name tulad ng LabMaterials.
  5. Itakda ang share permissions at folder security permissions ayon sa task.
  6. Sa client, buksan ang \\\\LAB-SERVER\\LabMaterials gamit ang tamang server name.

3. Understanding permissions

READ

Read

Maaaring tingnan at buksan ang files.

MODIFY

Modify

Maaaring magdagdag, mag-edit, o mag-delete ayon sa permissions.

FULL CONTROL

Full Control

Malawak na access; ibigay lamang kung kailangan.

Least privilege

Ibigay lamang ang pinakamababang access na kailangan para matapos ang trabaho. Mas madaling i-manage ang permissions gamit ang groups.

4. Verify access

  1. Buksan ang shared path mula sa client PC.
  2. Subukan ang read-only account at tiyaking hindi nito mababago ang files.
  3. Subukan ang authorized edit account kung bahagi ito ng lab.
  4. Kung access denied, i-check ang credentials, network reachability, share permissions, at folder security permissions.
Best practice: Gumamit ng backup, strong passwords, at user/group-specific permissions. Huwag i-share ang buong system drive.
