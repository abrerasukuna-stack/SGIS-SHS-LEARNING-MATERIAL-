Network Troubleshooting

Suriin ang mga posibleng sanhi nang sunod-sunod. Isang pagbabago lang sa bawat pagkakataon at itala ang resulta.

1. Walang network connection

  1. Tingnan ang power, Ethernet cable, Wi-Fi, at link lights.
  2. Patakbuhin ang ipconfig /all at tingnan kung valid ang IP configuration.
  3. I-verify ang subnet mask, gateway, at DHCP settings.
  4. Subukan ang ping sa gateway/server kung pinapayagan.

2. DNS o hostname problem

  • Subukan ang DNS lookup gamit ang nslookup hostname.
  • I-verify na ang client ay gumagamit ng tamang DNS server.
  • Kung domain environment, tiyaking naka-point sa approved domain DNS server ang client.
  • Huwag basta palitan ang DNS sa production network nang walang pahintulot.

3. Shared folder inaccessible

  • I-verify ang server name/IP at share path.
  • Suriin ang file-sharing service at kinakailangang firewall rules.
  • I-check ang account, credentials, at share/folder permissions.
  • Huwag i-enable ang insecure legacy protocols para lang lampasan ang error.

4. Printer issue

  • Tingnan ang printer power, paper, ink/toner, at error lights.
  • Suriin ang USB/network connection at host status.
  • I-check ang default printer, paused queue, at printer driver.
  • Kung access denied, i-check ang approved user permissions.

5. Useful commands

Show IP details
ipconfig /all
Check server reachability
ping 192.168.10.10
Check DNS lookup
nslookup lab-server
Renew DHCP configuration
ipconfig /release
ipconfig /renew
Remember

Maaaring i-block ng firewall ang ping kahit gumagana ang ibang services. Gamitin ang tamang host/IP para sa inyong lab.
