SERVER ADMINISTRATION

Windows Server & Active Directory

Introductory guide sa server preparation, domain services, at centralized account management.

Prerequisite

Kailangan ng supported Windows Server installation, administrator permission, at test network. Ang eksaktong steps ay depende sa Windows Server version at licensing.

1. Ano ang Windows Server?

Ang Windows Server ay operating system para mag-host ng services sa network. Maaaring gamitin ito para sa identity management, DNS, DHCP, file sharing, at print services depende sa edition at roles na naka-install.

2. Basic preparation

  1. I-verify ang hardware/VM requirements at gumawa ng backup o snapshot kung pinapayagan.
  2. I-install ang Windows Server mula sa trusted installation media.
  3. Mag-set ng strong administrator password at install ang updates.
  4. Bigyan ng descriptive computer name, halimbawa LAB-SERVER.
  5. Planuhin ang static IP kung kinakailangan ng server role; i-check muna ang existing network plan.
  6. Itala ang server name, IP, OS version, at mga role na kailangang i-install.

3. Active Directory Domain Services (AD DS)

Ang AD DS ay directory service na nag-oorganisa ng users, computers, groups, at policies sa isang Windows domain.

  • Domain: administrative boundary para sa shared identity directory.
  • User account: identity na ginagamit sa pag-authenticate.
  • Security group: tumutulong mag-assign ng permissions sa maraming users.
  • Organizational Unit (OU): container para mag-organize ng directory objects at mag-apply ng delegated administration/policies.
  • Group Policy: centrally managed settings para sa users at computers.

4. High-level domain deployment workflow

  1. Planuhin ang domain name at network design kasama ng instructor/admin.
  2. Siguraduhing tama ang server IP, hostname, time settings, at DNS plan.
  3. Sa Server Manager, gamitin ang Add Roles and Features para idagdag ang AD DS role kung bahagi ito ng lab.
  4. Pagkatapos ng role installation, sundin ang promotion wizard para gumawa ng bagong forest/domain o magdagdag sa existing domain — piliin lamang ang tamang lab scenario.
  5. Pagkatapos ng configuration, i-verify ang AD DS/DNS health at gumawa ng test user/group ayon sa lab instructions.
  6. Sa client PC, i-join ang domain lamang kapag may pahintulot at compatible ang Windows edition; gumamit ng authorized domain account.
Careful: Ang paggawa ng domain controller ay nakakaapekto sa network identity at DNS. Huwag i-promote ang personal o school production computer nang walang pahintulot. Huwag gumamit ng real account passwords sa screenshots o notes.

5. Verification ideas

  • Tingnan ang Server Manager kung healthy ang installed roles.
  • I-check ang event logs at role-specific diagnostic tools.
  • Subukan ang domain lookup at client sign-in gamit ang test account.
  • Itala ang errors at ayusin nang paisa-isa.
